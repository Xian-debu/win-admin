## 二、与判据原文不一致处的处理（已回写 docs/22 §5.1）

1. **C18-2 的 clip 分支用 `--force-clip` 验证，而不是等一个「天然无 TextPattern」的夹具**。
   本机实测：WPF TextBox/RichTextBox、WinForms、conhost 控制台**都有** TextPattern（conhost `chars=242`）；真正无 TextPattern 且可复制的窗口是 Chromium 在 a11y 未就绪时的状态，无法在套件里稳定复现（也不会在用户真机上去赌）。故给 `ops/read-text` 增加 `--force-clip`：跳过 UIA 直接走 ctrl+a/ctrl+c，用来验证**同一条注入通道**（保存剪贴板 → 聚焦 → 全选复制 → 还原），断言 `source:"clip"` + 文本一致 + `clipRestored:true` + 剪贴板内容回到哨兵值。真实回落路径（无 TextPattern 时不带 `--force-clip` 也会走这里）由代码同一分支覆盖。
2. **`ops/read-text` 的 `hwnd` 原样回显调用者写法**（`0x90cdc` 或十进制都行）。内部用它定位窗口，不作数值消费；m20 N5 原本按 `printf '0x%x'` 断言，实测回显十进制后放宽为「非空且与入参一致」。
3. **`wwin focus --yes` 只对 focus 容忍**。`list/info/close/state` 仍把 `--yes` 当未知参数 rc=2——它是「focus 从不注入，所以不需要确认」的语义，不是通用的宽容。
4. **C18-4 的文档断言落在 `--help`**（T24 时 SKILL 尚未改写）：四个旗标必须能在自己的帮助里 grep 到，T26 再让 SKILL 与新旗标对齐（m20 只管「文档说的旗标要真的存在」）。

## 三、实现要点

- `win/wuia.ps1`：`-ReadText` → RawViewWalker DFS（depth ≤30、节点 ≤6000），对每个有 Text 模式的元素取 `DocumentRange.GetText(-1)`，**取最长候选**；输出 `{ok,mode:"readtext",hwnd,text,chars,element,candidates,nodes}`，无候选 → `ENV_NO_TEXT` rc=3。
- `bin/wuia`：`--read-text`。
- `bin/wshot`：`--out` 目标路径映射——`/mnt/*` 直接转 Windows 路径；其它 WSL 路径先落到 `$APP_ROOT/tmp/shot-<sha1前8>.png`，成功后 `cp` 回目标，JSON 增 `wsl_path/mapped/windows_tmp`；复制失败 `EXEC_COPY_FAIL`（rc5）。
- `bin/wwin`：`focus` 接受并忽略 `--yes`，JSON 增 `ignoredFlags`。
- `ops/read-text`（新建，只读操作）：UIA TextPattern 优先；`--no-fallback` 直接 `ENV_NO_TEXT`；否则 ctrl+a/ctrl+c 回落（需 input grant，保存并还原剪贴板，`clipRestored` 如实上报）；`--force-clip` 强制走回落通道。

## 四、环境坑（已记 docs/11）

- **K67**：用 `Start-Process powershell -ArgumentList '-NoExit',...` 起的控制台窗口抢到前台后，winps 里的 `SetForegroundWindow` 全部失败（`ENV_NOT_FOREGROUND`），连本来能聚焦的 WPF 夹具都拒绝；`wwin close` 掉那个探针窗口后立即恢复。**验收前不要留前台控制台窗口**。
- **K68**：`winps -f` 的 payload（`win/*.ps1`）**不能带 BOM**——winps 自己会 BOM 化，双 BOM 会让 PowerShell 报 `…:9 字符: 21 赋值表达式无效` 且 `wuia --list` 都跑不起来；需要 BOM 的是被 `powershell -File` 直接启动的 `tests/helpers/*.ps1`（K62）。
- **K69**：jq 传参两坑——`--argjson h "0x90cdc"` 非法（JSON 没有 0x 前缀），要用 `--arg`；页面正文可达 150 KB+，`--arg t "$TXT"` 会撞 `Argument list too long`（ARG_MAX），改 `--rawfile t <tmpfile>`。
