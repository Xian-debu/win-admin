## 3. 诚实的限制

1. **遮挡必须先激活。** winput 的 S7 断言要求 WindowFromPoint 的根窗口 == 目标窗口；被 Edge 覆盖时点击被拒（ENV_WINDOW_MISMATCH）。ops 层因此统一「先 wwin focus，再点击」。这保留了「绝不盲点」的语义：激活失败就不点。
2. **前台锁需要双线程 attach。** 后台进程直接 SetForegroundWindow 会被 Windows 拒绝；只 attach 前台线程也无效；实测必须同时 attach 前台线程与目标窗口线程（wa-core 注释里记了实测时间）。
3. **模态对话框是子窗口。** 记事本的保存提示在 UIA 树里（depth 4 的 Button：保存/不保存/取消），但 `wwin list` 看不到它（无独立顶层窗口）。好处是 WindowFromPoint 根仍是主窗口，点击不被 S7 拒绝；坏处是「等对话框」不能靠 wwin，要用 ops/wait-for --uia-name。
4. **记事本会复用窗口加标签页。** 同一进程再开文件是新增 Tab（标题变 *文件名），不是新窗口；测试用标题区分，但真实任务里应把窗口当作「可复用容器」而不是「一次性」。
5. **Ctrl+A 依赖控件接受全选。** 对 Document/RichEdit 有效；对某些自定义控件可能无效，此时 fill 的 readback 会不匹配并报 matches=false（宁可报错不假装成功）。
6. **UIA 树可能很大。** ops/find-and-click 默认 depth 8 / max 2000，取第一个匹配；深层嵌套应用需要显式调深并接受更慢。
7. **测试自带 grant。** 若运行前无有效 grant，check-m4.sh 会签发 30 分钟测试 grant，退出时撤销并删除（输出里有 note），避免测试依赖人工状态。

## 4. 本轮踩到的坑（都已修，写进 docs/11）

1. `jq --argjson` 不接受 `0x` 十六进制 hwnd：必须 `H=$((H))` 转十进制。
2. `H="$(op_resolve_hwnd ...)" || exit $?` 会把错误 JSON 吞进变量：必须显式 `printf` 后再退出（N5 因此一度显示 code 为空）。
3. PowerShell 单行 `param()` 里每个参数行必须以逗号结尾，否则 `参数列表缺少右括号`（waopen 首批报错）。
4. 改了 `win/*.ps1` 必须 `bootstrap.sh --force` 才进 app/0.2.0，否则 `no JSON from payload`。
5. 记事本 alt+F4 会弹保存提示，不等于关闭；`wwin close` 发 WM_CLOSE 让应用自己决定。
