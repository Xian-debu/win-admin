## M1 · 只读（下一步，**待用户授权开工**）

### 目标

在不注入任何输入的前提下，证明三件事：

1. 截到的图**是**物理像素的屏幕（C1）；
2. 能从 UIA 语义树里**精确**找到窗口与控件（C2）；
3. UIA 给的 rect 与截图**对得上**（C3，误差 ≤2px）。

### 工作项

| # | 工作 | 产出 | 备注 |
|---|---|---|---|
| 1.1 | `wdiag` 前置体检（锁屏/前台/DPI/session/guard） | 原语 | Q2 的探测口子在这里试 `OpenInputDesktop` |
| 1.2 | `wshot`（DPI aware、全屏/区域/多显示器预留） | 原语 | 校验 2560×1600 |
| 1.3 | `wuia`（窗口枚举 + 树 + 条件过滤 + JSON） | 原语 | 中文编码必须在此解决 |
| 1.4 | `wwin list` | 原语 | |
| 1.5 | Q1 验证：把截图发给用户确认"我是否真看见" | 结论 | **阻塞项**，结果决定 L4 定位 |
| 1.6 | `tests/reports/` M1 报告 | 报告 | |

### 风险

- `wuia` 输出体积爆炸（Edge 有数千节点）→ 强制 `--depth` 默认 3 + `--filter`。
- 中文乱码若修不掉 → 退回"全部输出英文 key + 名称字段 base64"，但这是下策。
